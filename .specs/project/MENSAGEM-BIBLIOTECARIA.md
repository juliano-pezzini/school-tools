# Perguntas para a bibliotecária — sistema de cadastro de livros

Olá! Estamos preparando uma ferramenta para **agilizar o cadastro de livros** da
biblioteca da escola (ler o código de barras/ISBN do livro e já preencher o
registro). Para fazer isso do jeito certo, precisamos entender o sistema que você
usa hoje. São **três perguntinhas**:

1. **Qual programa/sistema** você usa para cadastrar os livros?
   - Pode ser o **nome** do sistema, o **endereço (site)** que você acessa, ou
     simplesmente uma **foto da tela** onde você cadastra um livro.

2. Você cadastra **pelo navegador** (Chrome, Edge — aquele que abre um site) ou é um
   **programa instalado no computador** (um ícone que abre uma janela própria)?

3. Quando vai cadastrar um livro novo, o sistema deixa **buscar pelo ISBN** (aquele
   número do código de barras) e **já traz título, autor e capa** sozinho? Ou você
   precisa **digitar tudo à mão**?

> Se puder mandar **um print da tela de cadastro de um livro**, ajuda muito — vale
> mais que mil explicações. 🙂

Obrigado!
