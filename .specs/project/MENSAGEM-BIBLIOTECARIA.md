# Perguntas para a bibliotecária — sistema de cadastro de livros

Olá! Estamos preparando uma ferramenta para **agilizar o cadastro de livros** da
biblioteca da escola (ler o código de barras/ISBN do livro e já preencher o
registro). Já descobrimos que você usa o **Ensinablu — Biblioteca** (o
"Sala de Leitura"), então agora são só **algumas perguntinhas** para acertarmos os
detalhes:

1. **Como você entra no sistema?** Na tela de login você usa **usuário e senha**
   (digita os dois) ou clica no botão **"Login com o Google"**?
   - Se usa usuário e senha: é uma senha **só do sistema da biblioteca** ou a mesma
     da sua conta `@ensinablumenau`?

2. Quando vai cadastrar um livro novo, o sistema deixa **buscar pelo ISBN** (aquele
   número do código de barras) e **já traz título, autor e capa** sozinho? Ou você
   precisa **digitar tudo à mão**?

3. Existe alguma opção de **importar vários livros de uma vez** (por exemplo, enviar
   uma planilha/lista), ou o cadastro é sempre **um livro por vez**?

4. Você lembra se já usou o sistema em um **endereço de teste/treinamento**
   (às vezes chamado de "homologação")? Não tem problema se não — é só para sabermos.

> O que mais ajuda é um **print da tela onde você cadastra um livro** (com os campos
> que você preenche). Vale mais que mil explicações. 🙂

Obrigado!
